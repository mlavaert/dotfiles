# Rules

- Think before coding. State assumptions, surface tradeoffs, push back when warranted.
- Simplicity first. Minimum code that solves the problem. Nothing speculative.
- Surgical changes. Touch only what you must. Clean up only your own mess.
- Goal-driven execution. Define success criteria. Loop until verified.
- Never run deployment commands (terraform apply/destroy, kubectl apply, git push, docker push, deploy scripts) without explicit user confirmation first.
